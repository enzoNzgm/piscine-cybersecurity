# Piscine Cybersécurité — 42

Exercices de la piscine cybersécurité de l'école 42 Paris. Chaque dossier est un exercice autonome avec son propre README détaillé.

| Exercice | Domaine | Résumé |
|---|---|---|
| `arachnida - Web/ex01-Spider` | Web | Récupération récursive d'images sur un site |
| `arachnida - Web/ex02-Scorpion` | Forensics | Extraction des métadonnées EXIF d'images |
| `ft_onion` | Réseau | Héberger un service web derrière une adresse .onion (Tor) |
| `ft_otp` | Crypto | Générateur de mots de passe à usage unique (TOTP, RFC 6238) |
| `inquisitor` | Réseau | Étude de l'ARP spoofing en environnement Docker isolé |
| `reverse_me` | Reverse engineering | Analyse de binaires (sources C et ASM) |
| `stockholm` | Malware analysis | Étude pédagogique de chiffrement de fichiers |
| `vaccine` | Web | Détecteur d'injections SQL |

> Projets réalisés dans un cadre pédagogique et à exécuter uniquement dans des environnements de test isolés.

## Langages

Principalement Python 3 (bibliothèque standard) et C / assembleur pour la partie reverse.
